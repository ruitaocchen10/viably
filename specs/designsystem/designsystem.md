# Viably Design System

Derived from the Home Screen in the Figma "Projects" file (viably page). All other screens are empty placeholders.

---

## Colors

| Token | Value | Usage |
|---|---|---|
| `background` | `#13131a` | App background |
| `surface` | `#1c1c28` | Card / sheet background |
| `surfaceCompleted` | `rgba(200,255,87,0.07)` | Habit card background when completed |
| `accentLime` | `#c8ff57` | Primary accent — today highlight, score, completed habit name |
| `accentPurple` | `#7c6aff` | Secondary accent — MVD tag, progress bar start |
| `accentYellow` | `#ffdb57` | Streak number |
| `textMuted` | `#6b6880` | Subtitles, labels, incomplete habit names |
| `textPrimary` | `#ffffff` | Headings, day numbers |
| `border` | `rgba(255,255,255,0.07)` | Card borders |
| `borderCompleted` | `rgba(200,255,87,0.07)` | Completed card border |

---

## Typography

Font family: **Syne**

| Token | Size | Weight | Usage |
|---|---|---|---|
| `heading` | 28pt | ExtraBold 800 | Greeting, daily score |
| `dayNumber` | 24pt / 28pt | Bold 700 | Inactive day numbers / today |
| `habitName` | 20pt | Medium 500 | Habit card title |
| `sectionLabel` | 16pt | SemiBold 600 | Section headers |
| `dayLabel` | 12pt | Medium 500 | Day-of-week abbreviation |
| `caption` | 12pt | Medium 500 | Score label, MVD hint text |
| `mvdTag` | 12pt | Medium 500 | MVD badge text |
